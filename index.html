Final Year Project — UMT FTKKI

Emergency Shelter
Management System

A web-based platform to digitise Malaysia's flood evacuation centre (PPS) operations — replacing manual paper-based processes with a centralised, real-time system.

System demo coming soon

About

ESMS enables real-time management of evacuation centres during flood disasters. Shelter coordinators can register evacuees, track occupancy, manage relief claims, generate reports, and receive automated capacity alerts — all from a centralised web dashboard.

Waterfall SDLC 3-Tier Modular Monolith UMT Final Year Project

Key features

Evacuee registration

Register & track all evacuees entering the shelter

Capacity monitoring

Real-time occupancy with automated alerts

Reports & claims

Individual and full evacuee reports for aid claims

Check-in / check-out

Track evacuee arrival and departure status

Mobile responsive

Accessible from any device on-site

Email alerts

Automated notifications to JKM on capacity thresholds
